# MSCW EXP Tracker

[Download the latest installer](https://github.com/jkrs-dev/MSCW-Exp-Tracker-Releases/releases/latest/download/MSCWExpTracker-win-Setup.exe)

Track MapleStory Classic World EXP per hour, time to the next level, and named sessions.

Requires Windows 11 24H2 or newer (64-bit). Run the installer, open MapleStory, and wait for the tracker to find it. Then start tracking.

From v0.1.8, open Settings to check for updates, download a new version, and restart when ready. Older versions need one manual install to gain the updater. Your settings and saved sessions are preserved.
